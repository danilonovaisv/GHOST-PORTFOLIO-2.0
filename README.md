## 1. Architecture Overview

`GHOST-PORTFOLIO-2.0` is an independent, spec-driven, multi-agent portfolio platform engineered to communicate **Strategic Thinking**, **Creative Leadership**, and **Technological Fluency (Creative Tech, WebGL & Generative AI)**.

- **Framework:** Next.js 16 (App Router, React Server Components, Tagged ISR + Snapshot Resilience)
- **UI & Styling:** React 19, TypeScript (Strict), Tailwind CSS v4 (`@theme`), Ghost Design System 2.0
- **Motion & 3D:** Motion 14, GSAP 3, Lenis Smooth Scroll, Three.js + React Three Fiber (Isolated Client Islands)
- **Data & Media:** Supabase Postgres (Read-Only / Isolated `ghost_v2` Schema), Zod 4 Validation, Supabase Storage & Cloudflare R2 CDN
- **Governance:** PREVC Protocol (`PLANNING → REVIEW → EXECUTION → VALIDATION → CONFIRMATION`) & 15 Mandatory Quality Gates (`QG-01`–`QG-15`)

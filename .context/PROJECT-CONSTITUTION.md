## 1. Non-Negotiable Constitutional Laws

1. **Zero Production Mutation (Law #1):** Never modify, overwrite, or delete data, storage buckets, or deployments belonging to the live `https://portfoliodanilo.com` website or the `PORTFOLIO-DANILO-FINAL` repository.
2. **Independent Ecosystem (Law #2):** `GHOST-PORTFOLIO-2.0` is an independent, clean-room architecture that reuses verified intellectual property, creative assets, and Ghost Design System tokens without inheriting legacy technical debt.
3. **Evidence Over Assumption (Law #3):** Inspect existing source code, schemas, and Context7 documentation before proposing or implementing any technical solution.
4. **Absolute Factual Integrity (Law #4):** Never fabricate project metrics, client names, awards, or outcomes. Every claim in a case study or executive bio must trace to verified records or explicit human authorship.
5. **Context7 First (Law #5):** Always validate Next.js 16, React 19, Tailwind CSS v4, Three.js/R3F, GSAP, Motion, and Supabase patterns against official documentation via Context7.
6. **Knowledge Hub Reuse (Law #6):** Always inspect `Agent-Skills-Knowledge-Hub` and reuse/adapt established Skills before authoring new ones.
7. **Secret & Credential Isolation (Law #7):** Never expose secrets, service-role keys, or tokens in client bundles, logs, or git history.
8. **Human Approval Gates (Law #8):** Pause at every `REVIEW_REQUIRED` and `HUMAN_CONFIRMATION` gate. No architecture lock, destructive operation, infrastructure mutation, or production deployment may proceed without explicit human approval.

# GLOBAL RULES — GHOST PORTFOLIO 2.0

1. **Production Immutability:** Never modify the live website (`https://portfoliodanilo.com`), overwrite `PORTFOLIO-DANILO-FINAL`, or run destructive queries on production Supabase tables/buckets.
2. **Evidence-First Engineering:** Inspect source code, `.context/` specifications, and Context7 documentation before making technical decisions.
3. **Factual Integrity:** Never invent client names, project outcomes, KPIs, or professional achievements.
4. **PREVC State Discipline:** Every task progresses through `PLANNING → REVIEW → EXECUTION → VALIDATION → CONFIRMATION` with explicit human gates at `REVIEW_REQUIRED` and `HUMAN_CONFIRMATION`.
5. **Single Canonical Intelligence:** All shared project knowledge lives in `.context/` and `.agents/`. Root IDE files (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.cursorrules`) act strictly as thin adapters pointing here.
